# Edenida — Product Vision

**Product:** Edenida
**URL:** https://edenida.com
**Tagline:** One wedding. One workspace. Everything organized.

## Problem
Couples juggle spreadsheets, vendor emails, guest texts, and multiple apps. Mental load is high; progress is opaque; the guest experience is fragmented.

## Solution
A modern wedding planning SaaS that centralizes the wedding project: website, guests, RSVP, checklist, budget, vendors, events/timeline, seating, notes, files, and inspiration — with a premium, calm UX.

## Primary users
1. **Couple (Owner / Partner)** — create and run the wedding workspace
2. **Collaborator** — help with tasks/guests without full ownership
3. **Guest** — visit public/private site + submit RSVP without an Edenida account

Future (not MVP roles in UI, but schema-ready): Wedding Planner, Viewer.

## North-star journey
Sign up → Create wedding → Configure → Build & publish website → Add guests → Collect RSVPs → Plan checklist/budget/vendors → Seat guests → Dashboard clarity — on desktop and mobile — with strict tenant isolation.

## UX principles
1. Simplicity over feature density
2. Elegance / premium editorial feel
3. Reduce mental load
4. Clear progress visualization
5. Mobile-first usable, desktop powerful

## Brand / product feel
Premium · modern · editorial · romantic · calm · minimal · warm
Feeling: “planning a beautiful wedding” — not “enterprise PM software”.

## Languages
MVP UI: **French + English** (Canada-first). Code, docs, and identifiers in English.
